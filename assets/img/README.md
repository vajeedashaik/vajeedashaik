# assets/img/

Drop your profile photo here as **`profile.jpg`** (or update
`config.yml` → `ascii_portrait.source_image` to point at a different
filename/format — anything Pillow can open works: `.jpg`, `.png`, `.webp`).

Until you add one, `scripts/generate_ascii_portrait.py` falls back to a
generic gradient silhouette so the pipeline works out of the box.

This file only exists so Git tracks this otherwise-empty directory —
delete it once `profile.jpg` is here, or just leave it.
